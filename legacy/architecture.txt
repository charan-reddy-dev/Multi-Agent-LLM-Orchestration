DATA FLOW FOR A SINGLE QUERY:

  1. Client → POST /query
  2. Orchestrator creates SharedContext (job_id, original_query)
  3. Router LLM decides: run DECOMPOSITION first
  4. Decomposition → subtasks with dependency graph → SharedContext
  5. Router decides: RETRIEVAL for each pending subtask
  6. Retrieval → multi-hop RAG (≥2 chunks) → claims with chunk citations
  7. Tools called (web_search, etc.) with retry logic
  8. Router decides: CRITIQUE
  9. Critique → per-claim confidence scores, flags specific spans
  10. Router decides: SYNTHESIS
  11. Synthesis → resolves contradictions → final answer + provenance map
  12. Router decides: DONE
  13. SharedContext serialized → DB
  14. SSE stream closes with final answer
